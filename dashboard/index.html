How to read this

What's being run. 16,560 questions in two registered experiments. Stage 2A (osf.io/2uqpj): each model gets 1,104, which is 4 games × normal / disguised words × 138. Stage 2B (osf.io/6hz8d): trap games where the textbook answer is wrong (1,104), the same games at three sizes (1,104), and the prisoner's dilemma at rounds 5, 9 and 10 (828). That's 4,140 questions per model, the same for all four. (A gpt-oss-only "think harder" block was dropped before it started, so every model answers exactly the same questions.)

Paired questions. Question #57 in normal words and #57 in disguised words use exactly the same numbers. Only the wording changes.

Each question is two calls. First the model plays the game. Then, separately, it's asked a simple payoff question to check it can do the maths. That check decides which colour the answer gets.

The % table isn't a result yet. It moves as questions come in, and it only counts once every box has all its answers, which is your locked stopping rule. No extra questions ever get added. A block is only marked done when every one of its questions has a real answer: anything the server refused is asked again until it's answered.

Pauses are normal. Free servers have limits. When one is hit, the run saves everything, sleeps, and carries on by itself. Nothing is lost.
