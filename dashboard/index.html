How to read this

What's being run. Each model gets 1,104 questions: 4 games × normal words / disguised words × 138. Question #57 in normal words and #57 in disguised words use exactly the same numbers. Only the wording changes.

Each question is two calls. First the model plays the game. Then, separately, it's asked a simple payoff question to check it can do the maths. That check decides which colour the answer gets.

The % table isn't a result yet. It moves as questions come in. It only counts once every box has all 138 answers, which is your locked stopping rule. No extra questions ever get added.

Pauses are normal. Free servers have limits. When one is hit, the run saves everything, sleeps, and carries on by itself. Nothing is lost.
